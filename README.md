# OrientaPro — Démo MVP

> Plateforme d'orientation entrepreneuriale inclusive pour porteurs de projet QPV / RQTH et structures d'accompagnement.

🔗 **Démo en ligne** : https://VOTRE-USER.github.io/orientapro-demo

## À propos

OrientaPro met en relation des porteurs de projet fragiles (Quartiers Prioritaires, Travailleurs Handicapés) avec des structures d'accompagnement (BGE, ADIE, France Active, h'up entrepreneurs), via un diagnostic IA en 15 minutes propulsé par **Mistral AI** (IA souveraine française).

## Fonctionnalités

- 📋 **Diagnostic porteur** en 5 étapes (15 minutes)
- 🎯 **Matching** avec 3 structures recommandées + score sur 100 + raisons explicites
- 💰 **Aides mobilisables** estimées (NACRE, ACRE, Quartiers 2030, AGEFIPH, ARCE…)
- 🧠 **Analyse IA Mistral** contextuelle par profil
- 🏛️ **Dashboard structure** avec 7 KPIs d'impact (RQTH, QPV, consentement)
- 📊 **Catalogue CRUD** complet
- ⬇️ **Export JSON/CSV** CRM-ready

## Stack

HTML autonome (un seul fichier, aucune dépendance). Compatible Chrome, Edge, Firefox, Safari. Fonctionne hors ligne.

## Démo guidée (5 min)

1. **Accueil** → présentation + bandeau Mistral AI
2. **Diagnostic** → cocher QPV, profil 26-35 / Grand Est / Restauration / Idée / Financement
3. **Résultats** → 3 structures + aides + IA Mistral
4. **Espace structure** → bouton « Accès démo BGE » (1 clic)
5. **Dashboard** → 7 KPIs + diagnostics (Fatou, Karim, Aïcha, Mohamed, Claire, Mamadou, Assia, Sophie)
6. **Catalogue** → CRUD complet
7. **Export** → téléchargement JSON / CSV
